# ☕ نظام كاشير القهوة - Coffee POS System

نظام كاشير أوفلاين بالكامل، مبني بـ Python + PyQt5 + SQLite، متوافق مع Windows 7.

---

## 📁 هيكلية المشروع

```
coffee_pos/
├── main.py                  # نقطة تشغيل النظام
├── requirements.txt         # المكتبات المطلوبة
├── database/
│   ├── db_setup.py          # تصميم قاعدة البيانات الكاملة (18 جدول)
│   └── data_access.py       # كل عمليات القراءة/الكتابة على قاعدة البيانات
├── ui/
│   ├── style.py              # التنسيق العام (ألوان، خطوط - ثيم قهوة)
│   ├── login_screen.py       # شاشة تسجيل الدخول
│   ├── shift_screen.py       # شاشات فتح/إقفال الشِفت
│   └── pos_screen.py         # شاشة الكاشير الرئيسية (البيع)
├── utils/
│   └── backup.py              # النسخ الاحتياطي التلقائي
├── assets/                    # (لصور المنتجات وشعار المحل لاحقاً)
└── backups/                   # مجلد النسخ الاحتياطية (يتولد تلقائياً)
```

---

## ▶️ طريقة التشغيل (بيئة التطوير)

```bash
pip install -r requirements.txt
python main.py
```

**بيانات الدخول الافتراضية:**

> ⚠️ لا تحط كلمات السر هون — حطّها بملف `.env` (راجع `.env.example`).  
> النظام بيجبر كل مستخدم يغيّر كلمته أول ما يسجّل دخول.

✅ **تحديث أمان**: كل مستخدم عندو الآن `salt` عشوائي خاص فيه (مش ثابت بالكود)،
وأي مستخدم لازم يغيّر كلمة سره أول ما يسجّل دخول (`must_change_password`) —
ما بيقدر يتخطى هاي الشاشة.

## ⚠️ ملاحظات تقنية مهمة

1. **الأمان**: كلمات السر مشفرة بـ SHA-256، لازم نغيّر كلمة سر admin قبل التسليم.
2. **Windows 7**: هاد الكود اتكتب ليتوافق مع Python 3.8 (آخر نسخة رسمية تدعم Win7). لما ننقله للجهاز الفعلي لازم نتأكد من تثبيت هاي النسخة بالضبط.
3. **البيانات المالية**: كل عملية بيع بتتسجل مع اسم الكاشير والوقت بدقة، وأي حذف أو تعديل حساس بينسجل بجدول `audit_log`.
4. **النسخ الاحتياطي**: يصير تلقائياً أول ما البرنامج يفتح كل يوم، بمجلد `backups/`. ينصح كمان بعمل نسخة إضافية يدوية على USB خارجي بشكل دوري.
