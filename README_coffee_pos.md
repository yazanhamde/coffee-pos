## 🎯 ما الذي يفعله هذا النظام؟

نظام كاشير متكامل مصمم للمقاهي والمحلات الصغيرة — يعمل بالكامل بدون إنترنت أو اشتراكات سحابية.

يشمل دورة عمل كاملة:
**تسجيل دخول** ← **فتح شِفت** ← **بيع وطباعة فاتورة** ← **إقفال الشِفت** ← **تقارير يومية/شهرية**

## ✨ المميزات

| الميزة | التفاصيل |
|---|---|
| 🔐 **صلاحيات متعددة** | مدير / كاشير — مع إجبار تغيير كلمة السر أول دخول |
| 🛒 **شاشة كاشير كاملة** | فئات + منتجات + خيارات (حجم، نوع حليب...) + ضريبة + خصم |

| 💾 **نسخ احتياطي تلقائي** | يومي عند التشغيل — يحتفظ بآخر 30 نسخة |
| 📦 **مخزون** | سحب تلقائي عند البيع (لو في وصفة مرتبطة) |

| 🏗️ **بناء EXE** | سكربت جاهز لبناء `.exe` قابل للتوزيع بدون Python |
| ☁️ **100% أوفلاين** | لا إنترنت، لا اشتراك، لا سيرفر |

## 🚀 التشغيل السريع

### 1. تثبيت المكتبات

```bash
pip install -r requirements.txt
```

### 2. تشغيل النظام

```bash
python main.py
```

### 3. بيانات الدخول الافتراضية

| المستخدم | اسم الدخول | كلمة السر | الصلاحية |
|---|---|---|---|
| مدير النظام | `admin` | `admin123` | مدير |
| فريد | `fareed` | `1234` | كاشير |
| سليمان | `sulaiman` | `1234` | كاشير |

## 🔄 الترقية من Windows 7 إلى 10 / 11

هذا النظام مصمم منذ البداية للترقية السلسة — **لا تحتاج لإعادة إعداد أو نقل يدوي للبيانات.**

### لماذا الترقية سهلة؟

قاعدة البيانات **لا تُخزَّن بجانب البرنامج**، بل في مجلد ثابت خاص بالمستخدم:

```
Windows 7/10/11:
  C:\Users\<اسمك>\AppData\Roaming\love.jo\coffee_pos.db
```

هذا المجلد لا يُمسح عند إعادة تثبيت البرنامج أو الترقية إلى جهاز جديد.

### خطوات الترقية (3 خطوات فقط)

**① انسخ قاعدة البيانات من الجهاز القديم:**
```
C:\Users\<اسمك>\AppData\Roaming\love.jo\coffee_pos.db
```
انقلها إلى USB أو أي وسيط.

**② على الجهاز الجديد (Windows 10/11):**

ثبّت Python (أي نسخة من 3.8 لـ 3.12):
```bash
pip install -r requirements.txt
```

**③ ضع قاعدة البيانات في نفس المسار:**
```
C:\Users\<اسمك>\AppData\Roaming\love.jo\coffee_pos.db
```

ثم شغّل البرنامج — **كل البيانات موجودة كما هي:** منتجات، فواتير، مستخدمين، تقارير.

### ترقية requirements.txt للأنظمة الحديثة

على Windows 10/11 يمكن استخدام مكتبات أحدث:

```bash
# بدل requirements.txt المقيّد بـ Win7، ثبّت:
pip install PyQt5 pyserial pyinstaller pywin32 openpyxl
```

> ملاحظة: `requirements.txt` الأصلي محدد بإصدارات Win7 فقط (`PyQt5==5.15.9`). على Win10/11 يمكن حذف قيود الإصدار.

## 🖨️ إعداد الطابعة الحرارية

النظام يدعم **3 أنواع اتصال** ويكتشف الطابعة تلقائياً:

```
1. USB (Windows Spooler) ← الأشيع والأسهل
2. Serial / COM Port     ← طابعات Serial قديمة
3. وضع محاكاة           ← بدون طابعة (لا يوقف عملية البيع أبداً)
```

### إعداد طابعة USB:

1. وصّل الطابعة وتأكد أنها ظاهرة في **الأجهزة والطابعات**
2. افتح **⚙️ الإعدادات** من شاشة الكاشير
3. اختر اسم الطابعة من القائمة
4. اضغط **اختبار طباعة**

### الطابعات المدعومة:

| الماركة | الموديل | الترميز المقترح |
|---|---|---|
| Epson | TM-T20, TM-T82 | `cp864` |
| Xprinter | XP-58, XP-80 | `cp864` أو `cp720` |
| Rongta | RP58, RP80 | `cp720` |
| طابعات حديثة | أي موديل | `utf-8` |

> لو ظهرت مربعات بدل حروف عربية: افتح `utils/printer.py` وحرّك الترميز المناسب لأول القائمة في `ENCODING_PRIORITY`.

## 🔒 الأمان

- كلمات السر مشفرة بـ **SHA-256 + Salt عشوائي** خاص بكل مستخدم
- **إجبار تغيير كلمة السر** على أول تسجيل دخول
- **Audit Log** لكل عملية حساسة (حذف، تعديل، خصم، تصفير كلمة سر)
- لا توجد بيانات مرسلة لأي خادم خارجي
